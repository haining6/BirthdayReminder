# 生日提醒

开发者：海宁 · 版本 1.0.0 · 安卓 8.0 及以上 · 安装包约 1.2 MB

提醒亲友生日和各种重要日子，支持公历 / 农历（含闰月），可在当天或提前若干天提醒。

## 功能

- **公历 / 农历**：内置 1900–2100 年农历表，离线换算；农历闰月、小月“三十”、2 月 29 日都会自动处理
- **年份可不填**：不知道出生年份也能记；填了会显示“58 岁生日”“10 周年”
- **提前提醒**：当天、提前 1/2/3/5/7/10/15/30 天，可多选
- **四种提醒方式**（每条可单独选择）
  - 通知：一定会发；当天的通知上可一键给对方打电话、发祝福短信
  - 来电响铃：像来电一样持续响铃 + 锁屏全屏界面，最长 1 分钟，可“10 分钟后再提醒”
  - 短信：用你选的卡发给你填写的号码（比如卡 1 发给卡 2）
  - 邮件：用你自己的邮箱（QQ / 163 / 126 / 139 / Gmail）给自己发
- **提醒记录**：每次提醒、短信、邮件的结果都会记在“设置 → 提醒记录”
- **备份**：导出 / 导入 JSON 文件（不含邮箱授权码）
- 深色模式自动跟随系统

## 为什么省电

不常驻后台、不轮询。只登记一个系统闹钟，每天到点唤醒一次，检查完立即排好第二天，然后退出。
开机、改时间后会自动重新登记；如果到点时手机关机，开机或打开 App 时会补发当天的提醒。

## 安全与隐私

- 无广告、无统计、无任何第三方 SDK；只用了 Google 官方 AndroidX / Jetpack Compose 库
- 发布版**不混淆**代码（`-dontobfuscate`），任何人用 jadx 等工具反编译都能直接读懂全部逻辑
- 数据只存在手机的 App 私有目录，`allowBackup=false`，不会被备份到任何云端
- 联网只用于连接你自己填写的 SMTP 邮件服务器（TLS 加密 + 校验证书），邮件客户端是约 150 行的自写代码
- 邮箱授权码用 Android Keystore 硬件密钥加密保存
- 权限说明：

| 权限 | 用途 | 何时申请 |
|---|---|---|
| 通知 | 弹出提醒 | 首次打开 |
| 发送短信 | 短信提醒 | 选择“短信”方式时 |
| 读取手机状态 | 仅用于列出双卡，选择用哪张卡发短信 | 点“发送卡”时 |
| 网络 | 邮件提醒 | 普通权限，无需申请 |
| 开机启动、精确闹钟、全屏通知、振动 | 准时提醒、来电式提醒 | 普通权限，无需申请 |

关于“报毒”：App 带有“发送短信”权限，部分手机自带的安全扫描可能会因此提示“含短信权限”之类的风险，这是按权限做的通用提示，不是检出病毒。
可以把 APK 上传到 [VirusTotal](https://www.virustotal.com) 自行用几十家引擎复查。

## 安装后建议设置（国产手机）

为保证后台准时提醒，在 App 的「设置 → 让提醒更准时」里点「打开应用详情」，然后：

1. 允许「自启动」
2. 省电策略选「无限制」/ 允许后台活动
3. 通知里打开「锁屏通知」「悬浮通知 / 横幅」
4. 小米 / 红米：其他权限里允许「后台弹出界面」「锁屏显示」（来电式提醒用）
5. 发送测试短信时如果弹出“是否允许发送短信”，选「始终允许」

## 编译

需要 JDK 17 和 Android SDK（platform 35）。本机已装在 `C:\Users\rucha\dev\`，双击 `build-apk.bat` 即可：
先跑全部测试，再生成签名好的 `生日提醒-v1.0.0.apk`。

- `keystore/haining-release.jks` + `keystore.properties` 是发布签名密钥（证书署名：CN=海宁）。
  **以后发布新版本必须用同一把密钥**，否则手机上无法覆盖升级，请务必另外备份这两个文件
- 测试：`app/src/test` 里有农历换算（1900–2100 每一天往返校验、历年春节）、日期计算，以及模拟运行界面的冒烟测试

## 代码结构

```
app/src/main/java/com/haining/birthday/
├─ core/     Lunar.kt 农历换算   Dates.kt 下次日期、岁数、提醒文案
├─ data/     Event 数据模型   Repo 存储   Prefs 设置   Secret 加密   EventLog 提醒记录
├─ remind/   Scheduler 每日闹钟   Reminder 发提醒   Notifier 通知/来电式响铃
│            SmsSender 短信   Smtp + EmailJob 邮件   RingActivity 来电界面
└─ ui/       MainActivity   HomeScreen 首页   EditScreen 编辑   SettingsScreen 设置   DateDialog 日期滚轮
```
